About

NS

I started out hand-coding tables in a text editor and never quite lost that love for clean markup. Structure first, style second.

These days I build layouts with CSS Grid and Flexbox. Over the past year I've completed a front-end development track focused on semantic HTML, responsive CSS and the fundamentals of accessible design.

I care about pages that load quickly, read well on any screen, and make sense to someone using a keyboard or a screen reader. I sketch layout ideas on paper before opening an editor, which keeps me honest about hierarchy.
